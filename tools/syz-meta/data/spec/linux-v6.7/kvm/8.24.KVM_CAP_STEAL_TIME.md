### 8.24 KVM_CAP_STEAL_TIME

Architectures: arm64, x86

This capability indicates that KVM supports steal time accounting. When steal time accounting is supported it may be enabled with architecture-specific interfaces. This capability and the architecture- specific interfaces must be consistent, i.e. if one says the feature is supported, than the other should as well and vice versa. For arm64 see [Generic vcpu interface](https://www.kernel.org/doc/html/v6.7/virt/kvm/devices/vcpu.html) "KVM_ARM_VCPU_PVTIME_CTRL". For x86 see [KVM-specific MSRs](https://www.kernel.org/doc/html/v6.7/virt/kvm/x86/msr.html) "MSR_KVM_STEAL_TIME".
