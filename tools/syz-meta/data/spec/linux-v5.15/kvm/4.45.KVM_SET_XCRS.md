### 4.45 KVM_SET_XCRS

Capability: KVM_CAP_XCRS

Architectures: x86

Type: vcpu ioctl

Parameters: struct kvm_xcrs (in)

Returns: 0 on success, -1 on error

```
struct kvm_xcr {
      __u32 xcr;
      __u32 reserved;
      __u64 value;
};

struct kvm_xcrs {
      __u32 nr_xcrs;
      __u32 flags;
      struct kvm_xcr xcrs[KVM_MAX_XCRS];
      __u64 padding[16];
};
```

This ioctl would set vcpu’s xcr to the value userspace specified.
